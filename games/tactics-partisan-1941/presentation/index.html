능선 초소

순찰을 며칠 지켜보고, 한 번의 매복으로 초소를 지운다. 이 화면은 정찰 단계에서 무엇이 보이는가를 data/ 의 실제 수치로 그린다.

01임무

세 임무가 각각 다른 사람을 반드시 요구한다. 수치는 mission.json 그대로다.

02구역 지도

지도에는 좌표가 없다. 구역과 인접 관계뿐이고, 배치는 연출이 정한다 (palette.json 의 layout). 실선은 걸어갈 수 있는 인접, 붉은 점선은 소음 차폐, 얇은 점선 화살표는 시선이다.

인접 (이동 · 소음) 소음 차폐 시선 굵은 흰 테두리 = 정찰 벤티지 점선 회색 = 정찰 사각

03순찰 시간축

두 순찰의 주기와 교대 시각. patrols.json 의 체류 시간에서 다시 계산했다 — src/PatrolModel.cs 와 같은 규칙이다. 흰 세로선이 교대 시각이다.

04감시 공백

이 표가 정찰의 산출물이다. 구역마다 "살아 있는 순찰병 누구에게도 보이지 않는 구간". 계획 단계에서 플레이어가 노리는 것이 이 줄무늬다. 사선 줄무늬가 공백이다.

05분대 3인

수단이 겹치지 않는다. 겹치면 한 명만 쓰는 최적해가 생긴다 (squad.json).

06소음이 닿는 범위

거리가 아니라 인접 몇 홉으로 판정한다. 한 홉마다 이 깎이고, 도착 음량이 미만이면 들리지 않는다.

수단음량닿는 홉이 지도에서 닿는 구역 (초소에서 냈을 때)

07거점

임무 사이에 빼앗은 보급으로 무엇을 고칠지 고른다 (camp.json).

08검사기 일곱

Phase는 "구현했다"가 아니라 "검사기가 통과한다"로 닫는다. 아래는 tests/ 에 실제로 있는 것들이다.

    기계가 판정할 수 없는 것 둘: 지켜보는 며칠이 지루한가, 매복이 터질 때 통쾌한가. 둘 다 사람이 플레이해야 안다 — README 의 판정 칸에 미확인이라고 적었다.
    에셋은 CC0 · 퍼블릭 도메인 · OFL 뿐이다 (CREDITS.md). 배경은 1941년 동부 전선 파르티잔이지만 실존 인물·부대·사건을 쓰지 않는다 — 무명의 가상 분대다.

    데이터를 읽지 못했다

    file:// 에서는 fetch 가 막힌다. 이 목업은 data/ 의 실제 JSON을 읽어 그리므로 작은 서버가 필요하다:

    cd games/tactics-partisan-1941 && python -m http.server 8731
    → http://localhost:8731/presentation/index.html
