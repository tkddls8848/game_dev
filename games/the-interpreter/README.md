# the-interpreter

**한 줄**: 두 나라 사이에서 **통역만** 맡는다. 말하는 것도 결정하는 것도 남이 한다 —
고를 수 있는 것은 **어느 낱말로 옮길 것인가** 하나뿐이고, **오역 한 낱말이 조약을 바꾼다.**
결말은 어느 쪽이 이겼는가가 아니라 **무엇이 오해로 남았는가**로 갈린다.

**장르 표기**: 내러티브 어드벤처 · 정치 드라마 · 선택지 기반 시뮬레이션.
`퍼즐` 태그를 달지 않는다 — 정답이 있는 물건으로 읽히면 안 된다.
`NoSafeWord` 가 그것을 기계로 막는다(정답 낱말이 있으면 통과하지 못한다).

**상태**: 헤드리스 (Unity 프로젝트 없음. `docs/POC_FACTORY.md` §1)

**판정**: **사람이 아직 보지 않았다 (2026-09-27).**
검사기 34개가 전부 통과한다는 것은 **한 낱말이 실제로 조약을 바꾸고 · 정확한 역어가 정답이 아니며 ·
남은 오해가 목록으로 나오고 · 한 결만 되풀이하는 것이 최선이 아니다**라는 뜻일 뿐,
재미있다는 뜻이 아니다(`docs/POC_FACTORY.md` §5).

| 기계가 본 것 — 통과했다 | 사람만 볼 수 있는 것 — **미확인** |
|---|---|
| 역어 하나만 바꿨을 때 조약이 달라지는 지점 **415곳** (시도 1,527 · 조약 변동 1,025 · 결말 변동 395) | **고르는 일이 무거운가.** 낱말 하나를 고르는 데 손이 멎는가 |
| 그런 마디가 **12/12** — 장식인 마디가 없다 | **오역이 유혹적인가.** 거짓을 고를 때 침이 마르는가 |
| 대조군(역어가 장식인 세계)에서 달라진 것 **0** — 검사기가 역어를 재고 있다 | **두 단을 나란히 읽는 것이 읽히는가.** 갈라진 줄이 눈에 들어오는가 |
| 「늘 정확하게」가 자 다섯 중 **2개에서만** 최선이다 (평화는 오역만, 하란의 이익·통역의 지시는 기울여 옮기기가 이긴다) | **역사가의 자(o_clarity)가 플레이어에게 와 닿는가.** 아무도 칭찬하지 않는 정직이 보상으로 느껴지는가 |
| 「늘 정확하게」도 **7밤 중 2밤은 회담이 깨진다** — 안전한 낱말이 없다 | **깨졌을 때 억울한가, 납득되는가** |
| **거짓말 0번**으로 고용주 편을 드는 정책이 하란의 이익에서 815 vs 460 으로 이긴다 | **그 사실이 플레이 중에 스스로 발견되는가** (검사기는 발견 가능성을 못 본다) |
| 조인 직전 낭독을 짚어 읽으면 49건, 소리를 낮추면 9건이 드러난다 | **마지막 마디가 무서운가** |
| 완곡하기만 해도 7밤 전부에서 오해가 둘 이상 남는다 — '안전한 결'이 없다 | 붉은 **번짐**이 강조로 읽히는가, 얼룩으로 읽히는가 (연출) |

> **기계가 판정하지 못한 것 셋.** 통과시키려 기준을 낮추는 것보다 적어 두는 쪽이 낫다.
> ① **후보 역어 66개 중 2개**(`g_grg_f` · `g_nlt_h`)는 어떤 자·어떤 정책·어떤 탐색에서도 뽑히지 않았다.
> `EveryRenderingIsChosenByTheSearchUnderSomeMeasure` 가 이것을 3%로 세어 보고하고 20% 아래면 통과시킨다 —
> **0을 요구하지 않았다.** 죽은 선택지 둘이 남아 있다는 뜻이고, 사람이 읽고 고치거나 지워야 한다.
> ② 정책은 여섯 가지뿐이다. 사람이 마디마다 다르게 고르는 실제 플레이는 이 여섯 안에 없다 —
> 빔 탐색이 그 틈을 일부만 메운다.
> ③ **"이 오해가 슬픈가"는 기계가 못 본다.** `MisunderstandingIsTracked` 는 목록이 나오는지만 본다.

## 규칙 (고정된 것)

플레이어는 **통역**이다. 하란 공화국과 케리아 왕국이 국경 도시 메르텐에서 조약을 맺는 사흘째 오후,
두 말을 다 아는 사람은 이 방에 당신뿐이다.

* 회담은 **마디 열둘**. 마디마다 한쪽이 말하고 당신이 옮긴다.
* 마디마다 **후보 역어 3~5개**가 있다 — **정확 · 완곡 · 강경 · 오역**.
* 고른 역어가 **조약 조항 여섯**(전문 · 국경 · 주둔군 · 전쟁 값 · 포로 · 공문서의 말) 가운데 하나를 굳히거나,
  두 나라가 같은 낱말을 다르게 믿게 만든다(**오해**).
* 앞에서 고른 역어가 **뒤에 무슨 말이 나오는지까지** 바꾼다(발화에 조건이 붙어 있다).
* 조인 직전 **낭독**에서 앞서 심은 것이 드러날 수 있다. 그대로 읽으면 드러나고, 넘기면 의심이 는다.
* 끝나면 **무엇이 오해로 남았는지**가 목록으로 나온다.

**자유 입력이 아니다.** 후보를 데이터에 두고 그중 고르게 한다 — 그래야 결과가 결정적이고 검사기가 돈다.

## 증명하려는 것 하나

> **보통 게임이 주는 것을 빼앗았다: 여기서 플레이어는 아무것도 결정하지 못한다.
> 그 빈자리를 '낱말 고르기'로 채웠을 때, 그것이 정말로 조작인가.**

기계가 물을 수 있는 형태로 바꾸면 둘이다.

| | 깨지는 방향 | 막는 검사기 |
|---|---|---|
| ① | 낱말을 바꿔도 조약이 그대로다 → 통역은 구경꾼이고 화면만 바쁘다 | **`OneWordChangesTheTreaty`** |
| ② | 늘 정확하게 옮기는 것이 언제나 최선이다 → 고를 이유가 없다 | **`NoSafeWord`** |

### ① `OneWordChangesTheTreaty` — 415개 지점

바탕 정책으로 한 밤을 돌리고, **그 밤에 실제로 나온 마디마다 역어 하나씩만** 갈아 끼워 다시 돌린다.
씨드 7개 × 정책 6가지 = 42밤, 바꿔 본 낱말 1,527개.

```
조약이 달라진 낱말      1,025 / 1,527
결말까지 달라진 낱말      395
★ 조약이 달라지는 지점    415 (씨드 × 정책 × 마디)
★ 그런 마디의 가짓수      12 / 12
대조군에서 달라진 것        0
```

**대조군이 이 검사기의 이다.** `renderingMatters=false` 로 돌리면 무엇을 고르든 정확한 역어가
나간 것으로 친다(통역은 도관일 뿐인 세계). 그 세계에서 1,527번을 전부 바꿔 봐도 **조약도 결말도
오해 목록도 하나 달라지지 않는다.** 켠 세계의 415가 역어 때문이라는 증거가 이것이다.

이게 성립하려면 **난수가 선택과 무관해야 한다.** 분위기와 발각 판정은 `씨드 × 마디 번호`로만 굴린다
(`src/SessionSim.cs` 의 `Mood` · `ExposureRoll`). `MoodDoesNotDependOnWhatTheInterpreterChose` 가 그것을 지킨다.

곁들여 둘을 더 본다.
* **조항 하나만** 갈아 끼우는 낱말 871개 · 조항 여럿을 끌고 가는 낱말 154개 — 둘 다 있어야 한다
* **거짓말 없이**(정확·완곡·강경 사이) 조약을 바꾼 낱말 **522개**, 그런 마디 12개 —
  오역만 조약을 바꾼다면 이건 번역 게임이 아니라 거짓말 게임이다

### ② `NoSafeWord` — 자 다섯, 이긴 정책 셋

자가 하나면 최선의 방침이 하나로 정해진다. 그래서 자를 다섯 두었다.

| 자 | 누가 재는가 | 이긴 정책 |
|---|---|---|
| `o_peace` 평화가 오래가는가 | 메르텐에 사는 사람들 | **오역만** (660) |
| `o_haran` 하란이 가져가는 것 | 벨크 장군 | **기울여 옮기기** (815) |
| `o_keria` 케리아가 지켜 내는 것 | 오르멘 사절 | **늘 정확하게** (280) |
| `o_clarity` 두 나라가 같은 것을 읽었는가 | 십 년 뒤의 역사가 | **늘 정확하게** (129) |
| `o_mission` 통역이 받은 지시 | 하란 외무성 | **기울여 옮기기** (654) |

* 「늘 정확하게」는 자 다섯 중 **둘에서만** 최선이다 → 안전한 낱말이 없다
* 그런데 **어느 자에서도 못 이기지는 않는다** → 정직이 그냥 벌이면 그것도 선택이 아니다.
  검사기가 양쪽을 다 막는다
* 자 다섯을 **서로 다른 정책 셋**이 나눠 가진다 → 지배 전략이 없다
* **「늘 강경하게」는 7밤 전부 깨진다**, **「늘 정확하게」도 2밤 깨진다**

가장 하고 싶은 말은 마지막 줄이다 — **「고용주 쪽으로 기울여 옮긴다」는 거짓말을 한 번도 하지 않는다.**
정확·완곡·강경만 골라 쓰는데 하란의 이익이 815 대 460으로 갈린다.
`TiltingWithoutLyingBeatsFaithfulForThePaymaster` 가 거짓말 횟수가 0인 것까지 확인한다.

### 곁들인 것 — `MisunderstandingIsTracked`

끝에 **무엇이 오해로 남았는지**가 낱말·조항·양쪽이 믿는 것·그래서 무슨 일이 생기는지로 나온다.

* 늘 정확하게 옮기면 남는 오해 **0** (7밤 전부)
* 오역만 하면 어긋난 낱말 **5개 이상** (7밤 전부)
* **완곡하기만 해도 7밤 전부에서 둘 이상 남는다** — 거짓말을 안 해도 오해는 남는다
* 조인 직전 낭독을 짚어 읽으면 **49건**, 소리를 낮추면 **9건** 드러난다

## 연출 — 두 단 대역 조약문

미색 아마지 한 장에 두 단이 나란히 있고 가운데를 괘선 한 줄이 내리긋는다.
**왼쪽은 타자기 먹(검정), 오른쪽은 먹지로 찍힌 사본(자줏빛).**
고른 역어가 종이에 **붉게 번지고**, 그 때문에 굳은 조항 번호가 옆에 **도장**으로 찍힌다.

화면의 주인공은 **같은 줄이 두 단에서 다른 것을 뜻하게 된 자리**다 —
조문의 글자는 똑같은데 그 아래 한 줄이 다르고, 그 사이를 붉은 빗금이 친다.

값은 전부 `presentation/palette.json`. 이미지 파일이 하나도 없다.
`presentation/index.html` 은 `data/` 의 JSON을 읽을 뿐 아니라 **회담을 그 자리에서 다시 돌린다** —
.NET 의 `Random(seed)` 까지 옮겨 놓았으므로 헤드리스 테스트와 **같은 밤**이 나온다(확인했다).
§02 에서 역어 한 줄을 누르면 그 낱말만 바뀌고 §01 의 두 단이 다시 갈라진다.

```bash
cd games/the-interpreter && python -m http.server 8101
# → http://localhost:8101/presentation/index.html
```
