## farm-erosion — 플레이 컨셉 티저 (10초)

`farm-erosion-teaser-10s.mp4` · 1916×1080 · 24fps · H.264 + AAC · 17 MB

**목적**: 이 게임이 **무엇을 하는 게임인지** 10초에 보여 주는 것. 분위기 영상이 아니다.
`밭이 줄어드는 세계`가 파는 정서는 "땅이 실제로 사라진다"이므로, 그 사건이 화면에 들어가야 한다.

**구성**

| 시간 | 장면 |
|---|---|
| 0–2s | 농장 전경. 카메라가 천천히 다가간다 |
| 2–4s | 선택 테두리가 칸에서 칸으로 옮겨간다 — 플레이어가 고르는 중 |
| 4–6s | 파도가 거세지고 붉은 점선 칸이 갈라진다 |
| 6–8.5s | **그 칸이 무너져 바다로 떨어진다.** 바위가 구르고 물보라가 솟는다 |
| 8.5–10s | 무너진 자리에 바위 더미만 남는다. 농장이 작아졌다 |

**만든 방법**: Artlist image-to-video (Kling 2.6 Pro), 1,500 크레딧.
입력은 `../lowpoly/farm-erosion-v1.png` (승인된 연출 시안) 한 장.

**결과에 남은 한계 — 쓰기 전에 알아야 한다**

* **UI가 후반에 사라진다.** 카메라가 밀고 들어가며 상단 자원 표시와 하단 버튼이 화면 밖으로
  밀려난다. 티저로는 깔끔하지만 "게임 화면"임을 증명하지는 못한다
* **카메라가 요청보다 많이 움직인다.** "고정 + 미세 푸시인"을 지시했으나 구도가 꽤 바뀐다
* **UI 숫자는 변하지 않는다.** image-to-video는 "남은 땅 16/24"를 15로 세지 못한다.
  실제 카운터 변화를 보여야 하면 엔진 녹화여야 한다

**스토어에 쓸 때**: Steam은 트레일러가 실제 게임플레이를 대표할 것을 요구한다.
이 영상은 **컨셉 전달용**이고, 메인 트레일러는 엔진 녹화로 만들어야 한다.
AI 생성물이므로 Steam AI 공시 대상이다 — `games/mystery-blackwood/docs/POSITIONING.md` §5의 방침을 따른다.
