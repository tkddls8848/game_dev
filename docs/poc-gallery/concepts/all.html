컨셉 시안 70 — 전체 정리

docs/CONCEPTS.md 의 컨셉 70개를 한 장에 모았다. 그 표의 상태 · 에셋 · 헤드리스 · 메모를 그대로 들고 왔고, 시안 화면은 이 페이지를 떠나지 않고 열어 본다 — 카드의 시안 화면 보기는 그 컨셉의 HTML 시안을 띄우고, 썸네일은 목업을 확대한다. 목업 이미지는 AI 생성 시안이지 실행 빌드 화면이 아니다(실행 화면에는 실행 표시를 달았다). 검사기를 통과한 21개도 재미 판정은 아직 아무도 하지 않았다 — 뿌리 CLAUDE.md 원칙 7.

70컨셉 49미착수 21구현 · 검사기 통과 292026-09-29 추가 70HTML 시안 140목업 이미지

이 파일은 그냥 두 번 눌러 열어도 된다 — 컨셉 시안 70개는 전부 자족형이라 file:// 에서 그대로 보인다. 다만 구현 PoC 20개 중 19개는 fetch 로 데이터를 읽어 file:// 에서 빈 화면이 된다(서버 표시를 달아 두었다). 그것까지 보려면 저장소 뿌리에서 python -m http.server 를 띄우고 localhost:8000/docs/poc-gallery/concepts/all.html 로 연다.
