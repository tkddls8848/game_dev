10초 전의 나

10초마다, 방금 10초 동안의 내가 붉은 유령으로 들어온다.
유령은 내가 한 그대로 움직이고, 내가 벤 자리를 그대로 벤다.

WASD · 방향키 이동  |  클릭 · Space 마우스 쪽으로 대시 베기  |  아무 키나 누르면 시작

베였다

R 다시  |  2 방금 판의 기록 보기

입력 기록 · 10초 창

한 줄이 유령 하나다. 색은 이동 방향, 흰 막대는 대시 베기. 같은 색이 같은 자리에 반복되면 그게 버릇이다.

결정성 확인

씨드 105 로 만든 입력 6,000틱(96초)을 엔진 없이 시뮬레이션해 매 틱 상태를 FNV-1a 로 접는다. 화면을 그리지 않는다.

아직 돌리지 않았다.

설계자 화면게임에는 없다. 규칙은 전부 정수이고, 유령은 AI가 아니라 입력 로그다 — 그래서 같은 입력이면 같은 판이 나온다.

규칙표 · 정수

틱16 ms시뮬레이션 단위. 화면 프레임과 무관
창625 틱= 10,000 ms. 창이 닫힐 때마다 유령 +1
이동7 / 틱대각선 5+5 (≈7.07). 아레나 1400 × 860
대시 베기8 틱 × 20= 160. 16방향으로 양자화한 조준
재사용36 틱576 ms. 대시 중에는 이동 입력 무시
칼 판정반경 56대시 중인 쪽이 56 안의 상대를 벤다
맞베기내가 이긴다둘 다 대시 중이면 유령이 지워진다
유예45 틱유령이 창 처음으로 돌아올 때마다 무해
입력 1틱9 bit상하좌우 4 · 대시 1 · 조준 4. 10초 = 703 B
