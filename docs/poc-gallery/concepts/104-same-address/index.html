같은 주소

두 게임이 메모리 256바이트를 나눠 쓴다. 한쪽의 금화가 다른 쪽의 체력이다.

양치기.exe1일째
공유 메모리Local\같은주소 · 256B
0x10목장: 양의 수 · 던전: 열리는 문 번호
0x11목장: 금화 · 던전: 영웅 체력
0x12목장: 날짜 · 던전: 층
지하감옥.exe체력 2
영웅 이동 — 방향키 / WASD, 또는 옆 칸 클릭. 문은 0x10 과 번호가 같을 때만 열린다.
계단에 닿았다
1층 통과 — 2층에서는 0x13 이 열린다
목표 던전 영웅을 계단(▼)까지 길 1 3번 문 — 양을 3마리로 맞추고, 가시 4칸을 버틸 금화를 모은다 길 2 1번 문 — 가시는 없지만 양을 1마리까지 팔아야 한다
패스스루. 2층부터 두 창이 하나로 합쳐진다. 규칙은 던전이 돌리고(보이지 않는 창), 화면은 목장이 그린다. 울타리는 벽, 엉겅퀴는 가시, 우리 문은 번호 문이다.

던전의 화면은 버리지 않는다 — 목장이 그 깊이만 빌려 자기 그림에 합성한다. 아래 막대를 밀면 숨은 던전 그림이 드러난다.
던전이 그린 것 목장이 그린 것
