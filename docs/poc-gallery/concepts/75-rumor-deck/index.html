정책별 결과

기존 덱빌더(54–59)와 다른 점

덱빌더는 보통 고르는 게임이다 — 상점·보상·제거로 덱을 다듬는다. 여기에는 상점도 보상도 없다. 카드 열 장이 끝까지 같은 열 장이다.

대신 쪽지는 쓸 때마다 스스로 변한다. 덱을 만드는 손은 플레이어가 아니라 장터 사람들이다. 플레이어가 고르는 것은 어디서 흘릴지 — 즉 누구 손을 거치게 할지뿐이다.
