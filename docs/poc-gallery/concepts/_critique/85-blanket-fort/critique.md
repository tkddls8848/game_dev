## 판정 (한 문장)

현재안은 방어 배치의 판단 근거가 부족하고 ‘엄마 기척’이 정답 하나인 중단 절차에 그쳐, 첫인상의 긴장감이 사라지면 반복할 이유가 약한 PoC다.

## 치명적 문제

1. **방어 선택은 보이지만 선택의 근거가 없다.** HTML A 하단에는 곰·손전등·병정·오르골과 가격이 있지만 사거리, 공격 주기, 저지 수, 적 상성은 없다. 오른쪽 아래 배치 윤곽도 어느 경로를 얼마나 막는지 알려주지 않는다. 사탕 7개로 곰+손전등을 살지 병정+오르골을 살지 판단할 정보가 부족하다. 손전등의 광선 지우기에 제약이 없다면 곰으로 막고 손전등으로 처리하는 조합이 지배할 위험이 있다. 제목과 달리 이불·베개로 요새를 **짓는 결정**도 자료에서는 확인되지 않는다.

2. **엄마 이벤트가 전술을 끊지만 전술을 바꾸지는 않는다.** HTML B는 괴물과 장난감이 모두 멈춘 가운데 ‘손전등 꺼!’와 Space를 지시한다. 적도 정지한다면 즉시 끄고 기다리는 행동에 방어상 손해가 없다. 충분히 예고하면 반복 입력 숙제이고, 예고가 짧거나 불분명하면 한 번의 입력 실수로 끝나는 반응속도 시험이다. 원문의 ‘게임 종료’와 화면의 ‘밤이 끝나요’는 손실 범위도 다르다. 둘째 판에 적 구성·배치·엄마 기척이 어떻게 달라지는지 없어 재도전이 암기 이상의 배움을 줄 근거가 없다. 구조적으로는 **Plants vs. Zombies**식 역할별 방어에 **Five Nights at Freddy’s**를 연상시키는 야간 위협 대응을 붙인 수준에 머물 위험이 있다.

3. **HTML은 목업의 공간과 물성을 전달하지 못하며, 이를 메우는 작업이 1주 일정의 병목이다.** 목업 A는 의자에 걸친 이불의 처짐, 봉제인형의 털, 바닥에 닿는 그림자와 조명으로 장난감의 존재감을 만든다. HTML A는 정면 벽·수직으로 내려다본 침대·납작한 요새의 시점이 충돌하고, 오른쪽 침대가 큰 면적을 차지해 전장을 압축한다. ‘꽉 막았다!’·‘지워지는 중!’은 결과를 설명하지만 접촉과 소멸의 과정은 정지 화면만으로 입증되지 않는다. 목업 B의 낮은 시점과 문틈 발 그림자는 HTML B에서 먼 문과 빛으로 약화되고, 거대한 중앙 문구가 상황을 덮는다. 목업 B까지 구현 기준이면 카메라 전환과 추가 공간 연출도 필요하다.

## 개선 요구

1. **[규칙] 가격 위주의 구매 → 경로별 투자 판단으로 바꿀 것.** 다음 적의 출입구·특성·도착 순서를 예고하고, 배치 미리보기에 사거리와 저지 대상을 표시한다. 곰의 저지 한도, 손전등의 과열, 오르골의 적용 대상을 명시해 같은 예산에서도 적 구성에 따라 유효한 조합이 달라지게 한다.

2. **[규칙] 무조건 끄기 → 방어 중 선택의 결과가 이어지는 정숙 준비로 바꿀 것.** 장난감별 정지 준비 시간을 두고, 엄마 접근 예고 동안 공격을 더 유지할지 먼저 끌지 선택하게 한다. 실제 검사 중에는 모두 정지하되, 예고 중 포기한 공격과 재가동 지연이 다음 교전에 남게 한다. 손전등 끄기와 숨 참기의 입력·유예 시간·실패 조건을 각각 확정한다.

3. **[규칙] 막연한 밤 반복 → 재현 가능한 학습 단위로 바꿀 것.** 승리 시점, 사탕 수급, 요새 피해, 발각 시 손실을 정의한다. 실패 화면에는 누수 경로·누적 피해·발각 원인과 입력 시점을 남기고 같은 씨드 재도전과 새 씨드를 구분한다. ‘요새 짓기’를 유지한다면 베개 배치가 경로 또는 저지에 미치는 규칙도 필요하다.

4. **[규칙] ‘헤드리스 ◎’ → 판정 경계를 명세할 것.** 경로 진행도·사거리·피해·정숙 준비·발각을 정수와 ms 기반 순수 C#으로 계산하고, 고정 씨드와 입력 기록으로 재현한다. 발각 경계 시점과 정지 중 피해 발생 여부를 검사한다. 첨부 코드의 `Math.random()`은 그레인 생성용이므로 규칙 비결정성의 증거는 아니다. 반대로 발소리를 알아듣는지, 꺼짐이 즉시 느껴지는지는 헤드리스로 검증할 수 없다.

5. **[시안] 설명문 중심 화면 → 행동과 상태가 직접 읽히는 화면으로 바꿀 것.** A의 카메라·가구 원근을 통일하고 충돌부 압축, 크레용 소멸, 광선 방향, 배치 범위를 구현한다. B의 중앙 문구는 짧게 제시한 뒤 줄이고 문틈 그림자·남은 유예·꺼야 할 대상을 우선 표시한다. 발소리의 거리 변화, 정숙 전환, 스위치음과 실제 입력 반응을 녹화·청취로 검증한다. 현재 자료로 소리와 움직임의 품질은 판정할 수 없다.

6. **[시안] 1주 안에 전부 구현한다는 가정 → 제작 병목을 먼저 검증할 것.** 첫 단계에서 목업 수준의 방 한 구역, 곰의 저지, 괴물 지우기, 정숙 전환을 실제 실행으로 완성한다. 물성·조명·크레용 애니메이션·공간음이 일정에 맞지 않으면 품질을 낮추지 말고, 줄일 콘텐츠와 카메라 범위를 구체적으로 제시해 합의한다.

## 유지할 것

옷장과 침대 밑의 두 진입로, 실물 장난감과 크레용 괴물의 재질 대비, 방어 중 따뜻한 빛이 정숙 순간 사라지는 전환.
