## 판정 (한 문장)

현재 화면만으로는 ‘거인의 보행에 대응하는 농업’이 추천 작물 누르기로 축소되고, 목업의 감각 품질을 실제 조작으로 연결하지 못해 PoC가 실패할 위험이 크다.

※ 파일 읽기가 실행 환경 오류(`bwrap: Operation not permitted`)로 차단되어 지정 문서·소스는 확인하지 못했다. 아래는 첨부 4장에 근거한 조건부 비평이며, 원문 규칙의 부재를 단정하지 않는다.

## 치명적 문제

1. **결정의 비용은 숨기고 정답처럼 보이는 표시는 앞세운다.** HTML A 오른쪽은 벼 ‘적합’, 메밀 ‘부적합’을 제시하지만 파종 비용·성장 기간·예상 수확량은 없다. 상단의 ‘2일 후 소나기, 5일 후 고원’과 비교할 시간 정보가 없어 장기 판단이 불가능하다. 추천이 장기 전망까지 반영한다면 추천 따라 심기가 지배 전략이 되고, 현재 상태만 반영한다면 설명 없이 오답을 유도한다. ‘흙 유실 −3/걸음’ 역시 남은 토량과 회복 수단 없이 불안만 만든다. 기울기 때문에 **어떤 행동을 바꿔야 하는지**가 드러나지 않는다.

2. **여정의 결말은 있지만 반복할 이유와 실패에서 배울 구조는 보이지 않는다.** HTML B의 마지막 수확·주민·계절 수는 합계일 뿐, 어떤 파종이나 물 관리가 손실을 만들었는지 설명하지 않는다. ‘내려간다/남는다’도 결과 차이가 보이지 않아 전략적 결산보다 감상 선택에 가깝다. 같은 기후 순서라면 두 번째 판은 일정 암기가 될 위험이 있고, 예고 없는 무작위라면 실패는 운 탓이 된다. 거대 생물 등 위 정착이라는 소재 자체는 이미 [The Wandering Village](https://thewanderingvillage.com/)와 겹친다. 기울기가 계단 사이의 자원 배분을 바꾸지 못하면 차별점은 외형에 머문다.

3. **HTML과 목업은 같은 품질 목표에 도달한 시안으로 보기 어렵다.** 목업 A의 핵심은 계단식 경작지·수로·낙수·주민 작업이 연결된 지형이다. HTML A는 거인의 빈 몸통과 전경 구름이 대부분을 차지하고 밭은 얇은 띠로 압축된다. ‘7번 계단’ 말풍선도 대상 경계를 명확히 보여주지 않는다. 목업 B의 숙인 머리와 손, 계곡은 정지와 하차를 설명하지만 HTML B는 같은 측면 실루엣의 축소에 가까워 ‘처음 땅에 닿음’이 전달되지 않는다. 목업 A의 목재·돌·빵과 HTML의 식량·저수·유실, 목업 B의 밀·당근과 HTML의 벼·보리는 규칙 합의도 흔든다. 이를 해결할 지형 제작·애니메이션·상호작용 정합성이 1주 일정의 병목이다.

## 개선 요구

1. **[규칙] 적합도 정답 표시 → 시간과 비용을 비교하는 선택으로 바꾼다.** 작물마다 수확까지 남은 걸음, 물 소비, 재파종 손실, 예고된 기후를 반영한 수확 전망을 표시한다. 지금 유리한 벼와 고원 도착 전에 거두는 작물 사이에 실제 상충관계를 만든다.

2. **[규칙] 기울기 설명문 → 계단별 물·흙 이동 규칙으로 바꾼다.** 상류의 취수가 하류 수확을 줄이는 식으로 행동의 외부효과를 정한다. 전 구역 동일 작물·항상 추천 작물 전략을 여러 고정 씨드에서 비교해, 한 전략이 모든 조건을 압도하는지 검증한다.

3. **[규칙] 합계형 결산 → 원인 추적 가능한 실패와 재도전으로 바꾼다.** 식량 고갈·경작지 손실의 임계값을 명시하고, 손실 직전 결정과 대안을 기록한다. 동일 씨드 재도전과 조건이 다른 씨드를 제공하되, 판단에 필요한 예보는 행동 전에 공개한다.

4. **[규칙] 시각적 물리 의존 → 순수 C#의 정수 상태 전이로 분리한다.** 계단을 연결 그래프로, 물·토량·성장을 정수로, 보행을 고정 틱으로 정의한다. 이동 계산 순서와 나머지 배분을 고정하고 동일 씨드·입력의 상태 해시, 물 수지, 음수 자원 발생을 검사한다. 흔들림·낙수 입자는 판정 결과를 표현하게 한다.

5. **[시안] 멀리 있는 밭과 분산된 수치 → 선택·파종·결과가 이어지는 화면으로 바꾼다.** 선택 계단에 경계선과 물 흐름을 표시하고, 클릭 전후 수확 전망과 비용을 같은 위치에 둔다. ‘다음 걸음’의 조작 가능 여부와 소모 시간을 명확히 한다. 작물·자원 체계는 A/B와 목업에서 통일한다.

6. **[시안] 배경 중심 품질 확인 → 실제 입력과 보행 연출 검증으로 바꾼다.** 파종 반응, 발 디딤의 저음, 수로음, 몸과 마을의 지연 흔들림, 정지 순간의 소리 변화를 함께 검증한다. 정지 이미지만으로 소리·움직임 품질은 판정할 수 없다. 첫 제작 검증부터 목업 수준의 밭과 거인 일부를 실제 조작으로 연결하고, 일정 부족을 기본 도형으로 대체해 완료 처리하지 않는다.

## 유지할 것

‘보행 → 기울기 → 물과 흙의 이동 → 농사 결과’라는 인과축과, 마지막 정지가 생활 방식을 바꾸는 결말 구조.
