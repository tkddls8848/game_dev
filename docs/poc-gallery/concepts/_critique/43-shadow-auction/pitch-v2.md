# 그림자 경매 (v2)

**한 줄**: 경매에 나온 것은 물건이 아니라 물건의 그림자다. 조명을 옮기면 **모두가** 새 그림자를 본다

**장르**: 추리 · 경매 · 규칙 헤드리스 ◎ / 그림자·반응 판독은 실제 플레이 검증

## v1 → v2 변경 요약

- **도감(가설판)을 먼저 준다.** 로트마다 후보 2~3개의 정체·감정가·출품 비율·각도별 그림자 특징을 입찰 전에 공개한다. 관찰로 후보를 지우면 기대값과 가치 범위가 정수로 계산된다. '흔들림 없음' 같은 근거 없는 단서는 없앴다.
- **단서 하나로 확정되지 않는다.** '가는 선'은 진품의 받침 막대이기도, 복제의 쇠 지지대이기도 하다. 둘을 가르는 것은 90°에서만 보이는 선의 끝 높이다.
- **조명은 공개 정보다.** 각도를 사면 경쟁자도 같은 그림자를 본다. 정보를 사면 가격이 움직인다. 이 트레이드오프가 각도 선택과 입찰 경쟁을 묶는다.
- **입찰자 반응은 장부로 배운다.** 인물별 전문 분야·이해관계·반응 규칙이 고정되고, 장부가 맥락(위탁자, 공개된 각도)별 적중률을 쌓는다. 런을 넘어 남는 것은 번호 암기가 아니라 '누가 무엇을 아는가'다.
- **경제·종료 조건을 명시했다.** 좌석료 때문에 관망에도 비용이 들고, 파산은 '관전 전환'이라는 실제 상태다. 복기는 '당시 증거'와 '해설'을 나눈다.

## 한 밤의 규칙 (모두 정수, 단위 원·ms)

| 항목 | 값 |
|---|---|
| 시작 현금 · 로트 수 · 밤 목표 | 3,000원 · 6로트 · 밤 종료 시 현금 **3,600원 이상** |
| 좌석료 | 로트마다 100원 (입찰·관망 무관, 로트 시작 시 차감) |
| 조명 | 0°(정면) 무료. 45°·90° 각 **200원**, 산 즉시 차감. 로트당 최대 2회. 조명 이동 1,500ms 동안 호가 정지 |
| 입찰 | 호가 단위 100원. 마지막 입찰 뒤 경매사 박자 3회 × 1,200ms → 낙찰 |
| 낙찰 | 즉시 가림막 공개 → 감정가로 경매장 감정실이 매입(현금 환급). 로트 손익 = 감정가 − 낙찰가 − 조명비 − 좌석료 |
| 관전 전환 | 현금 < 다음 로트 시작가 + 좌석료이면 남은 로트는 관전만 한다(좌석료 없음). 반응은 계속 장부에 기록되고, 밤은 실패로 끝난다 |
| 기대값 | Σ(감정가 × 비율) ÷ Σ비율, 남은 후보만. 정수 나눗셈 후 100원 단위 내림 |

관망만 하면 3,000 − 600 = 2,400원으로 목표 미달 → '확실한 로트만 기다리기'는 지는 전략이다.

## 예시 — LOT 04 · 학 조각상 (시안 A·B의 숫자)

도감: **진품**(청동 주조, 운송용 받침 막대) 2,600원 · 비율 2 / **석고 복제**(청동 도색, 내부 쇠 지지대) 200원 · 비율 2 / **후주조 복제**(청동) 800원 · 비율 1.
특징: 0° 날개 끝(진품·석고 뾰족, 후주조 뭉툭) · 45° 다리 옆 가는 선(진품·석고 있음, 윗끝은 다리에 가려짐) · 90° 선의 끝(진품 발목, 석고 배).

현금 흐름: 3,000 → L1 관망 2,900 → L2 좌석료·45°·낙찰 900·감정 1,400 → 3,100 → L3 조명 2회 후 관망 2,600 → **L4 좌석료·45° → 2,300원(시안 A)**.
A 시점: 0° 뾰족 → 후주조 제외. 45° 선 있음 → 진품/석고 2:2, **기대값 1,400원 · 범위 200~2,600원**. 현재가 1,200원(11번). 11번 빠른 패들 0.4초(장부: 진품 4/5), 3번 헛기침(개인 위탁 로트 진품 2/4 = 신호 없음).
선택: 90°를 산다(−200, 모두가 봄) / 기대값 상한까지 입찰 / 관망.
**시안 B**: 11번을 믿고 1,700원에 낙찰 → 석고 복제, 감정 200원. 로트 손익 −1,800원, 현금 **800원**. 복기: 당시 판단은 기대값 1,400원 대비 **300원 초과**, 11번의 빠른 패들은 나와 같은 45°만 보고 나온 반응(장부 분할: 90° 공개 후 4/4 · 공개 전 0/2). LOT 05 참가비 500원(시작가 400 + 좌석료 100) → 참가 가능, 목표까지 2,800원.

## 런을 넘어 남는 것

- **입찰자 장부**: 6명 중 밤마다 씨드로 3~4명 출석. 인물의 전문·이해관계·반응 규칙은 고정, 로트의 정체는 도감 비율로 씨드 추첨. 장부는 반응 × 맥락(위탁자, 공개된 최대 각도, 재질)별 적중/표본을 누적한다.
- 예: 3번(중개인)은 **경매장 위탁** 로트에선 진위를 아는 바람잡이, 개인 위탁 로트에선 1,000원을 넘길 때마다 헛기침하는 버릇일 뿐. 11번(청동 수집가)은 공개된 그림자만으로 판단하고 가는 선을 받침 막대로 과신한다(진품 확신 +20%p, 상한 1,600원) — 내가 모르는 것을 아는 사람이 아니다.
- **도감 채움**: 공개된 물건은 90° 그림자까지 도감에 남아 다음 밤에 같은 종류의 특징 판독을 돕는다. 정체는 매번 새로 추첨되므로 '학은 가짜'라는 암기는 통하지 않는다.

## 검증 경계

- **헤드리스(순수 C#, 정수·ms·씨드)**: 자금 흐름, 좌석료·조명비, 입찰·낙찰·박자, 가설 소거와 기대값, 경쟁자 상한·반응 지연(확신 60% 이상 400ms, 아니면 1,200ms 이상), 장부 집계, 관전 전환·목표 판정. 씨드 1만 밤 시뮬로 전략 비교: 항상 관망 < 신호 무조건 신뢰 < 기대값 상한 + 장부 필터 이어야 한다.
- **실제 플레이 검증**: 가는 선이 실제 광원·모델 그림자에서(가로 축소 계산이 아니라) 45°엔 모호하고 90°엔 판독되는지, 헛기침·패들 속도가 소리·동작으로 구별되는지, 입력→패들 상승·가격 갱신 지연, 공개 전환의 시선 순서.
- **사람 판정**: 복기가 '놀림'이 아니라 '내 판단 검증'으로 느껴지는가, 다음 로트를 하고 싶은가.

## 차별점

《Modern Art》는 가치가 입찰자 합의로 정해지고, 《Papers, Please》는 규칙표와 대조한다. 여기서는 **정보를 사는 행위가 곧 정보를 공개하는 행위**다. 90°를 켜는 순간 가격이 뛰거나 무너지고, 경쟁자의 반응이 '나보다 더 아는가'를 장부로 가려야 한다.
