# 비·눈·날씨 — 이펙트 샘플

`index.html`을 브라우저로 연다(file:// 가능, 외부 의존 없음). 첫 클릭 후 소리가 난다.

| # | 변형 | 컨셉 | 조작 | 기법 |
|---|---|---|---|---|
| 1 | 유리창 빗방울 · 김서림 | 18 보내지 못한 것 | 드래그=김 서린 유리에 쓰기, 클릭=유리 톡 | 법선맵 물방울 → WebGL 굴절(상 뒤집힘), 멈칫거리며 흐르는 방울·병합·자국, 김 마스크 |
| 2 | 우산 위 빗소리 | 92 우산 대여점 | 누르고 있기=우산 펴고 걷기 | 빗줄기 착지점 선결정 → 우산/땅 분기, 낙수 고리, 우산 속 차음(저역통과)+타닥 |
| 3 | 쌓이는 눈 · 녹는 몸 | 93 눈사람의 겨울 | 가지 클릭=눈 떨구기, 눈사람 클릭=몸 떨기, 빈 곳=바람 | 표면별 1px 열 높이 배열 + 안식각, 덩어리가 떨어져 다시 쌓임(보존), 햇빛 슬라이더로 녹음 |
| 4 | 번개 섬광 · 천둥 지연 | 88 자판기의 마음 | 클릭=그 지점으로 번개 | 씨드 중점 변위 번개, 섬광 키프레임, 번쩍 버전 배경(숨은 인물), 거리/343초 천둥, 자판기 전압 강하 |

공통 키: 1–4 선택 · Space 발동 · R 초기화 · M 소리 · S 성능 모드.
검증: 헤드리스 Chromium에서 변형별 조작 후 캡처 확인, 페이지 오류 0. 실제 GPU 60fps·소리 만족도는 사람 판정.
