# 필름·사진 현상 — 효과 샘플

`index.html`을 브라우저로 연다(file:// OK, 외부 의존 없음). 첫 클릭 후 소리가 켜진다. `?solo=N`(0–3)은 한 변형만 갱신한다(저사양·검증용).

| # | 변형 | 컨셉 | 입력 → 반응 | 기법 |
|---|---|---|---|---|
| 1 | 폴라로이드 현상 | #8 찍히지 않은 사람 | 클릭 → 셔터·배출 모터음 → 현상 / 드래그 → 흔들기(가속·펄럭임) | 픽셀별 진행도 `t − delay(uv)`, 청→저채도→최종색 3단 mix, 빈자리 그림자 지연 |
| 2 | 확대경 루페 | #7 사진 속 범인 | 이동 → 루페 / 클릭 → 초점 펄스·단서 표시 / 휠 → 배율 | 장면 함수 재호출 확대 + 배럴 왜곡 + R/B 색수차, 사진 좌표 그레인 |
| 3 | 영사 필름 빛샘·그레인 | #36 늘어진 테이프 | 클릭 → 재생(영사기 18Hz·포먼트 목소리) / 드래그 → 와우 | 18fps 양자화 결함(흔들림·먼지·깜빡임) + fbm 빛샘, 재생 횟수 열화가 화면·음정 동시 저하 |
| 4 | 인화지 광택·뒷면 | #26 한 사람의 유품 | 이동 → 기울기 광택 / 클릭 → 뒤집기 | 블린-퐁 + 휨 법선, 긁힘·지문은 반사광에만, cos 스케일 뒤집기 |

각 변형의 파라미터(정수·ms)는 오른쪽 패널에서 조절하고 JSON으로 복사한다. 이식 메모는 패널 "구현 메모".
