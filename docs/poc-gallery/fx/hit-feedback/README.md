# 타격·보상 피드백 — 효과 샘플

`index.html`을 브라우저로 연다(file:// OK). 첫 클릭 후 소리가 켜진다. `?solo=N`은 한 변형만 갱신.

| # | 변형 | 컨셉 | 입력 → 반응 | 기법 |
|---|---|---|---|---|
| 1 | 카드 사용 → 적 타격 | #55 · #54 · #57 | 카드 드래그/클릭 → 비행·트레일 → 히트스톱·흔들림·번쩍·숫자·HP 칩 | 베지어 비행 + 가산 리본 트레일, 트라우마² 흔들림, 3층 타격음, 치명타 단계 |
| 2 | 활자 인쇄 · 소모 | #56 소모되는 활자 | 클릭 → 들어올림·내리찍기·히트스톱·잉크 튐 | 3박 타이밍, 남은 횟수에 비례한 인쇄 결손(fbm 임계), 카운터 롤·떨림, 0회 균열 |
| 3 | 콘페티 · 관객 호응 | #9 · #13 | 클릭 → 폭죽·콘페티·박수·아르페지오·게이지 오버슈트 | 양면 종이 조각(cos 뒤집힘, 저항, 팔랑임), 노이즈 알갱이 박수 합성 |
| 4 | 픽셀 타격 · 리뷰 별점 | #90 거꾸로 던전 | 클릭 → 가시 함정 → 정수 픽셀 흔들림·2프레임 번쩍·넉백·픽셀 숫자·리뷰 카드 | 저해상 캔버스 업스케일, 프레임 단위 히트스톱, 칩튠 합성 |

히트스톱은 `v.freeze`(ms) 동안 시뮬레이션 dt만 0 — 렌더·소리는 계속된다(공용 코어 `loop`).
