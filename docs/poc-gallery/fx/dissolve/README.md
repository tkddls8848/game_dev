# 용해·디졸브 — 효과 샘플

`index.html`을 브라우저로 연다(file:// OK, WebGL 필요). 첫 클릭 후 소리가 켜진다. `?solo=N`은 한 변형만 갱신.

| # | 변형 | 컨셉 | 입력 → 반응 | 기법 |
|---|---|---|---|---|
| 1 | 빛에 사라지는 사람 | #6 빛이 닿지 않는 것 | 클릭 → 손전등 / 이동 → 빛 닿은 곳만 먼지로, 어둠에서 역수렴 | CPU 침식 격자(80×60) → 텍스처, fbm 임계 + 창백한 경계, CPU 입자 풀 |
| 2 | 이름을 얻고 떠나는 신 | #101 이름 없는 신당 | 클릭 → 금빛 가루로 상승·이름 떠오름 / 재클릭 → 역재생 | 공유 임계 `thr(uv)` + 무상태 GPU 입자(역재생 공짜), 금색 연소 가장자리, 범종 합성 |
| 3 | 로그 삭제 · 픽셀 붕괴 | #2 삭제 직전 로그 | 클릭 → 글자 단위로 붕괴·낙하 / 재클릭 → 복원 | 글자 칸 양자화 임계, 지워지는 칸만 찢김, 스냅된 사각 입자, CRT |
| 4 | 전시물 → 내 물건 | #34 · #30 | 클릭 → 먼지 소용돌이를 거쳐 다른 형체로 / 재클릭 → 되돌리기 | 두 형체 N점 샘플 · y 정렬 짝짓기 · 사인 소용돌이 모프 |
