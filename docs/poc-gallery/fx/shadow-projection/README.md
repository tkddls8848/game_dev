# 그림자 투영 (shadow-projection)

`index.html`을 브라우저로 연다(file:// 가능, 외부 파일 없음). 상단 탭 또는 `#v=0..3`으로 변형을 고른다.

| 변형 | 조작 | 핵심 |
|---|---|---|
| #73 그림자 경매 | 드래그 ←→ 조명 궤도 · 클릭 각도 권리 사용 | 점광원 궤도 → 3D 청동 학 실루엣이 바뀜, 막 투과 조명 |
| #9 인형극 대결 | 드래그 인형 · 인형 클릭 달려들기 · 빈 곳 클릭 촛불 | 램프 쪽으로 갈수록 커지고 흐려지는 그림자, 흔들리는 불꽃 |
| #15 수면 아래 스텔스 | 드래그 다이버 · 클릭 조약돌 | 천창 평행광 2개, 수면 굴절 변위 + 코스틱, 은신 판정(수학) |
| #40 버스가 오지 않는 저녁 | 드래그 ←→ 시각 · 클릭 기다리기 | 해 고도 → 긴 그림자, 해 지면 가로등(두 번째 그림자) |

기법: 볼록 다면체의 광원 향한 면만 평면에 원근 투영 → 면광원 K표본 가산 누적(반영). 합성은 `주변광 + 광원×(1−그림자)`.
Canvas2D만 사용. Unity 이식 메모는 페이지 오른쪽 "구현 메모".
