# 연기·안개·비행운 — 이펙트 샘플

`index.html`을 브라우저로 연다(file:// 가능, 외부 의존 없음). 첫 클릭 후 소리가 난다.

| # | 변형 | 컨셉 | 조작 | 기법 |
|---|---|---|---|---|
| 1 | 봉화 연기 기둥 | 75 봉화 네트워크 | 연조 클릭=점화/소화, 우클릭=연기색 | 노이즈 퍼프 스프라이트 + 컬노이즈 + 고도별 바람, 불빛이 연기 밑면을 물들임 |
| 2 | 비행운 획 | 91 비행운 서예 | 드래그=비행하며 연기 분사 | 거리 기준 방출(5px), 속도→굵기, 고도 전단으로 번짐 |
| 3 | 안개 층 + 창 불빛 | 20 연결하면 안 되는 통화 | 집 클릭=통화 연결, 드래그=안개 헤치기 | WebGL 도메인 워핑 fbm 3겹 + 광원 산란, 안개 구멍 메움 |
| 4 | 굴뚝 연기와 돌풍 | 58 겨울 요새 | 클릭=돌풍 | 공간을 지나가는 돌풍 파면(좌→우 지연), 눈 줄무늬·지붕 눈가루 |

공통 키: 1–4 선택 · Space 발동 · R 초기화 · M 소리 · S 성능 모드(선택 변형만 재생).
오른쪽 패널의 "게임 이식용 값"은 현재 슬라이더 값을 JSON으로 보여 준다. 이식 방법·함정은 패널의 "구현 메모".

검증: 헤드리스 Chromium(SwiftShader)에서 변형별 클릭/드래그 후 캡처로 연출 확인, 페이지 오류 0.
헤드리스는 소프트웨어 래스터라 FPS를 신뢰할 수 없다 — 실제 GPU 브라우저에서 60fps 확인은 사람 몫.
