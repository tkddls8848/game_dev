# 종이·도장·찢김 — 이펙트 샘플

`index.html`을 브라우저로 연다(file:// 가능, 외부 의존 없음). 첫 클릭 후 소리가 난다.

| # | 변형 | 컨셉 | 조작 | 기법 |
|---|---|---|---|---|
| 1 | 도장 쾅 — 히트스톱·잉크 번짐 | 25 분실물 창고 · 68 신의 비서 | 왼클릭=승인, 오른클릭=반송, 누르고 있기=더 번짐 | 예비→내려찍기→접촉→히트스톱→흔들림→떼기 타임라인(ms), 압력 노이즈 잉크 마스크 + 번짐 |
| 2 | 종이 찢기 | 48 붉은 펜으로 남긴 것 | 원고를 가로질러 드래그 | 경로 재표본화+섬유 지터, 저항 있는 찢김 끝점, 거리당 소리 알갱이, 둘레 매개변수로 두 조각 분할 |
| 3 | 편지 접기 → 봉투 | 68 신의 비서 | 클릭 | 띠 24줄 슬라이스로 원근 rotateX, 뒷면 전환, 오버슈트, 봉투 덮개·봉인 |
| 4 | 서류 넘김 (페이지 컬) | 64 원고 되돌려 보내기 · 7 | 모서리 드래그 / 클릭=자동 | 수직이등분선 접는 선 + 반평면 클리핑 + 반사 변환, 책등 기준 원 제약, 원호 스냅 |

공통 키: 1–4 선택 · Space 발동 · R 초기화 · M 소리 · S 성능 모드.
검증: 헤드리스 Chromium에서 프레임을 직접 진행(FX.step)하며 타임라인 단계별 캡처 확인, 페이지 오류 0. 손맛(히트스톱·흔들림 강도)은 사람 판정.
