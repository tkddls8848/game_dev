# 불·불씨·촛불 — 이펙트 샘플

`index.html`을 브라우저로 연다(file:// 가능, 외부 의존 없음). 첫 클릭 후 소리가 난다.

| # | 변형 | 컨셉 | 조작 | 기법 |
|---|---|---|---|---|
| 1 | 촛불 — 숨결·소등 | 69 저주 장부 | 빠르게 지나가기=흔들림, 누르고 있기=불어 끄기, 꺼진 뒤 클릭=성냥 | 베지어 불꽃 3겹 + 불꽃 따라 움직이는 방사형 어둠, 소등 연기 한 줄 |
| 2 | 봉화 점화 · 불씨 | 75 봉화 네트워크 | 클릭=점화/장작, 누르고 있기=풀무질 | 수명 구간별 불꽃 스프라이트(가산) + 혀 모양 스프라이트, 딱! 소리 = 불씨 폭발 같은 사건 |
| 3 | 신당 촛불 · 이름 완성 | 101 이름 없는 신당 | 촛불 클릭=켜기/끄기, 5개 완성 | 촛불마다 오음계 방울, 완성 시 금빛 불씨 나선 수렴 + 영이 떠남 |
| 4 | 문서 연소 (디졸브) | 60 능선 초소 | 클릭=점화, 드래그=횃불로 훑기 | WebGL 연소장(점화점 16개) + 같은 노이즈로 CPU가 불테를 찾아 불씨 방출 |

공통 키: 1–4 선택 · Space 발동 · R 초기화 · M 소리 · S 성능 모드.
검증: 헤드리스 Chromium에서 변형별 조작 후 캡처 확인, 페이지 오류 0. 실제 GPU 60fps·소리 만족도는 사람 판정.
