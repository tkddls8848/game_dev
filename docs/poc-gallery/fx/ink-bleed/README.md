# 잉크·붓 번짐 (ink-bleed)

`index.html`을 연다(WebGL2 + EXT_color_buffer_float 권장). `#v=0..3`.

| 변형 | 조작 | 핵심 |
|---|---|---|
| #14 마지막 화자 | 드래그 붓 · 클릭 먹방울 · 빠른 튕김 | 한지 섬유 따라 깃털 번짐, 기필·수필, 비백, 먹 튐 |
| #75 봉화 네트워크 | 드래그 넓은 붓 · 클릭 맑은 물 | 옅은 수묵 번짐, 맑은 물로 되번짐(back-run) |
| #99 먹물 문어 | 드래그 먹 줄기 · 클릭 분사 | 물속 컬 노이즈 이류, 먹 가장자리 생물 발광 |
| #69 저주 장부 | 드래그 주묵 · 클릭 낙인 | 느린 증발 + 세로 섬유 → 획이 끝난 뒤에도 붉게 번져 감 |

상태 = 물·떠 있는 안료·마른 안료(RGBA16F 핑퐁). 종이 투수율 지도가 번짐 모양을 정하고, 색은 Beer–Lambert 흡광.
