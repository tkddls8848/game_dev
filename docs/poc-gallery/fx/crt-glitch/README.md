# CRT·글리치 (crt-glitch)

`index.html`을 연다(WebGL2 필요). `#v=0..3`.

| 변형 | 조작 | 핵심 |
|---|---|---|
| #1 해킹 탈출 방 | 타이핑·Enter · 클릭 유령 반격 | 블록 찢김·행 뒤섞임·색 분리·문자 오염 + 비트크러시 |
| #2 삭제 직전 로그 | 클릭 rm -rf | 호박색 단색, 전원 차단(세로→가로 접힘→잔광 점), 소자 재점등 |
| #53 작물이 정보다 | 드래그 동조 다이얼 · 클릭 수신 | detune 하나가 스노·롤·동기 흔들림·찢김을 구동, 고정 시 "탁" |
| #54 되감는 전투 | 누르고 있기 되감기 | VHS 트래킹 띠·헤드 스위칭·색 번짐, 테이프 모터음 |

구조: 2D 캔버스로 내용 → 패스 A(신호 결함 + 형광체 잔상 FBO 핑퐁) → 패스 B(곡면·수렴·스캔라인·애퍼처·글로우·전원 접힘).
