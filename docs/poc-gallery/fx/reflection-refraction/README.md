# 반사·굴절 — 효과 샘플

`index.html`을 브라우저로 연다(file:// OK, WebGL 필요). 첫 클릭 후 소리가 켜진다. `?solo=N`은 한 변형만 갱신.

| # | 변형 | 컨셉 | 입력 → 반응 | 기법 |
|---|---|---|---|---|
| 1 | 창문 반사 속 다른 승객 | #29 창문 속 괴물 | 이동 → 시차 / 클릭 → 실내등 깜빡임, 복귀 시 “그것”이 한 칸 가까이 | 바깥+반사 반대 시차 가산 합성, 터널 등에 씻기는 반사, 이중 반사 |
| 2 | 수면 아래 스넬 창 | #15 수면 아래 스텔스 | 이동 → 시선 / 클릭 → 수면 파문 | 역투영 → 수면 교차 → `refract`/전반사, RGB 분산, 슐릭 투과 |
| 3 | 수면 경계 굴절 · 발걸음 | #16 익사한 집 | 클릭 → 위층 발걸음(등 흔들림·먼지·파문) / 이동 → 수위 | 반잠김 분기, 1.33배 확대 “꺾임”, 전반사 거울 띠, 코스틱 |
| 4 | 김 서린 창 닦기 | #30 종점 | 드래그 → 성에 닦기(뽀드득), 시간이 지나면 재응결 | 2D 마스크 텍스처, 다중 탭 블러·산란·물방울 굴절, 흘러내림 |
