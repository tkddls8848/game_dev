# 음파·메아리 링 (sonar-echo)

`index.html`을 연다. `#v=0..3`.

| 변형 | 조작 | 핵심 |
|---|---|---|
| #94 메아리 지도 제작자 | 클릭 손뼉 · 드래그 발소리 | 청록 링, 벽 발광, 메아리 도착 시각에 양피지 지도 잉크, 파형 띠 |
| #31 빙판 탈출 | 클릭 발 구르기 | 흰 링이 지나며 균열만 붉게, 얼음 분산 처프 |
| #22 시력을 잃는 하루 | 클릭 지팡이 톡 | 넓고 흐린 호박색 링, 가구 윤곽이 잠깐 떠오름, 눈꺼풀 비네트 |
| #12 내려가는 곳 | 클릭 딩 · 드래그 ↕ 엘리베이터 | 좁은 통로 다중 반사, 층 문 표지, 화면 밖 깊이의 늦은 메아리 |

방출 시 광선 N개를 선분 지형에 한 번 추적(반사·재질) → 링은 경로 보간, 벽 발광은 충돌 목록.
소리는 같은 충돌 목록으로 임펄스 응답을 즉석 생성해 ConvolverNode에 건다 — 화면·지도·소리가 한 시각표.
